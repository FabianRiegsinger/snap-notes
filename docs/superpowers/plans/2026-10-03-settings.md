# Settings System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persisted, live-editable visual settings (sliders in five groups plus a palette editor), opened from a gear slot in the strip or with Cmd/Ctrl+,.

**Architecture:** `App` owns a `SettingsStore` and passes `&Settings` (or its sub-structs) explicitly into the layout, animation and view code that currently reads constants. A new `settings_panel.rs` renders the panel, which morphs out of the gear slot the same way a note morphs out of its bar.

**Tech Stack:** Rust 2021, iced 0.14, serde/serde_json, tempfile (tests).

**Spec:** `docs/superpowers/specs/2026-10-03-settings-design.md`

## Global Constraints

- Defaults equal today's constants exactly: bars 6/30/12, magnification 4.0, spread 60, peek delay 1.0 s, note 320/560, paper tint -0.12, idle control alpha 0.3, speed 1.0, stiffness 300, height fraction 0.9, palette = `PALETTE`.
- Ranges: width 3–12, height 16–60, gap 4–24, magnification 1–6, spread 20–120, peek delay 0.3–3, size 240–440, expanded 400–800 (≥ size), tint -0.3–0.3, idle alpha 0–1, speed 0.5–2, stiffness 150–600, height fraction 0.5–1.0.
- `MAGNIFICATION_STIFFNESS` stays a constant.
- `settings.json` lives next to `notes.json`. It is written with temp file + rename and a 500 ms debounce.
- **Height fraction on passthrough platforms:** there the window covers the whole monitor. `height_fraction` therefore limits the strip's layout bounds to the vertically centered `height * fraction` band. On other platforms it keeps sizing the window, as today.
- After every task: `cargo test` passes, and `cargo clippy --all-targets -- -D warnings` is clean.

## Review Focus

1. **Settings file from an older or newer version** with unknown or missing keys. It must load, keep the known values and default the rest. (Task 1: `partial_json_fills_defaults`, `unknown_keys_ignored`.)
2. **Hand-edited `settings.json` with NaN-like or out-of-range numbers or a 3-color palette.** Values must clamp and the palette must reset to the default. (Task 1: `out_of_range_values_clamp`, `wrong_palette_length_resets`.)
3. **A palette edit to a color that two slots share after an earlier edit.** Only notes with the old hex are recolored, and the other slot keeps its color. (Task 2: `recolor_changes_only_matching_notes`.)
4. **Dragging "expanded size" below "size" in the panel.** `expanded_size` must follow so it never drops below `size`. (Task 1: `set_keeps_expanded_at_least_size`.)
5. **Gear slot when there are zero notes.** It still sits below the add button with its own hit area. (Task 3: `gear_slot_below_add_button_for_any_count`.)

### Task 1: Settings model and store

**Files:**
- Create: `src/settings.rs`
- Modify: `src/main.rs` (add `mod settings;`)

**Interfaces:**
- Produces:
  - `pub struct Settings { pub bars: BarSettings, pub hover: HoverSettings, pub notes: NoteSettings, pub motion: MotionSettings, pub window: WindowSettings, pub palette: Vec<NoteColor> }`
  - The sub-structs and their fields:
    - `BarSettings { width, height, gap }`
    - `HoverSettings { magnification, spread, peek_delay_secs }`
    - `NoteSettings { size, expanded_size, paper_tint, idle_control_alpha }`
    - `MotionSettings { speed, stiffness }`
    - `WindowSettings { height_fraction }`
  - All fields are `f32`. Everything derives `Debug, Clone, PartialEq, Serialize, Deserialize` with `#[serde(default)]` at struct level and a `Default` impl holding the Global Constraints defaults.
  - `pub enum SettingsGroup { Bars, Hover, Notes, Motion, Window, Palette }`
  - `pub enum SettingKey { BarWidth, BarHeight, BarGap, Magnification, Spread, PeekDelay, NoteSize, ExpandedSize, PaperTint, IdleControlAlpha, Speed, Stiffness, HeightFraction }`, deriving `Debug, Clone, Copy, PartialEq, Eq`.
  - Methods on `SettingKey`:
    - `pub const ALL: [SettingKey; 13]`
    - `pub fn range(self) -> RangeInclusive<f32>`
    - `pub fn group(self) -> SettingsGroup`
    - `pub fn label(self) -> &'static str`
    - `pub fn format(self, v: f32) -> String`. Units: `px` for bar and note sizes, `×` for magnification and speed, `s` with 1 decimal for peek delay, `%` for height fraction, tint and idle alpha. Spread and stiffness are bare integers.
  - `impl Settings`:
    - `get(&self, SettingKey) -> f32`
    - `set(&mut self, SettingKey, f32)` clamps to the key's range. Setting `NoteSize` above `expanded_size` raises `expanded_size`. Setting `ExpandedSize` below `size` is clamped up to `size`.
    - `clamp(&mut self)` handles every range plus `expanded_size >= size`. A non-finite value becomes the default. A palette whose `len() != 20` becomes `PALETTE.to_vec()`.
    - `reset(&mut self, SettingsGroup)`
    - `pub fn open_width(&self) -> f32`
  - `pub const PRESETS: [NoteColor; 60]`: 12 hues (0°, 30°, …, 330°) × 5 tints, generated as HSL with saturation 0.75 and lightness ∈ {0.45, 0.55, 0.65, 0.75, 0.85}. Write it as literals so it can be `const`.
  - `pub struct SettingsStore`, mirroring `NoteStore`:
    - `load(path) -> Self` (clamps after load)
    - `save(&self) -> io::Result<()>`
    - `settings(&self) -> &Settings`
    - `settings_mut(&mut self) -> &mut Settings` (marks dirty)
    - `should_save`, `did_save`
  - `pub const STRIP_WIDTH`, `NOTE_GAP` and `NOTE_MARGIN` stay where they are. `open_width` needs `NOTE_GAP` and `NOTE_MARGIN`: move them to `pub(crate)` in `app.rs`, or into `settings.rs` re-exported to `app.rs`. Pick one and keep a single definition.

### Task 5: App owns settings and applies them live

**Files:**
- Modify: `src/app.rs`, `src/main.rs`, `src/note_panel.rs`

**Interfaces:**
- Consumes: everything from Tasks 1–4.
- Produces:
  - `App.settings: SettingsStore`, loaded in `boot` from `data_dir().join("settings.json")`. `data_path()` becomes `data_dir() -> PathBuf`, and the `notes.json` join moves to the caller.
  - `App::apply_settings(&mut self) -> Task<Message>`. It is called after any settings change and does three things:
    - updates `self.morph` and `self.peek` speeds with `set_speed`
    - clamps `scroll_offset` to the new `max_scroll`
    - sets `animating = true` and returns `dock_window()`
  - `PostIt` gains `paper_tint: f32` and `idle_control_alpha: f32`. Remove the `PAPER_LIGHTEN` and `IDLE_CONTROL_ALPHA` constants from `note_panel.rs`.

  - `dock_window` (non-passthrough) uses `settings.window.height_fraction`.
  - `strip_layout()`, when `SUPPORTS_PASSTHROUGH`, uses bounds `y = h * (1 - f) / 2` and `height = h * f`. The `bar_strip` widget receives the same band through a new `band: (f32, f32)` parameter (top, height) and lays out inside it.
  - `SaveTick` also saves settings when `should_save()`. `Quit` saves both stores.
  - Every place that passed defaults in Tasks 2–4 now passes the values from `self.settings`.

### Task 6: Settings panel

**Files:**
- Create: `src/settings_panel.rs`
- Modify: `src/app.rs`, `src/main.rs` (`mod settings_panel;`)

**Interfaces:**
- Consumes: `Settings`, `SettingKey`, `SettingsGroup` and `PRESETS` (Task 1), `NoteStore::recolor` (Task 2), `StripLayout.settings_button` (Task 3), `Morph` and `morph_frame` (existing).
- Produces:
  - New `Message` variants: `CloseSettings`, `SettingChanged(SettingKey, f32)`, `ResetGroup(SettingsGroup)`, `PaletteSlotSelected(Option<usize>)` and `PaletteColorChosen(NoteColor)`. `ToggleSettings` already exists.
  - `pub struct SettingsView<'a> { settings: &'a Settings, size: Size, content_alpha: f32, selected_slot: Option<usize> }`
  - `pub fn settings_panel(v: SettingsView<'_>) -> Element<'_, Message>`
  - New `App` fields: `settings_open: bool`, `settings_morph: Morph` and `palette_slot: Option<usize>`.
  - `App::settings_frame() -> Option<MorphFrame>` morphs from `strip_layout().settings_button` to a 360 px wide target rect. The height is `min(window_h - 2 * NOTE_MARGIN, 600)`. The rect sits right-aligned at `window_w - STRIP_WIDTH - NOTE_GAP` and is vertically centered on the gear, clamped to the margins.

**Behavior:**
- **`ToggleSettings`:** if settings are open, close them. Otherwise close any open note (`ClosePanel`), `hide_peek`, then `settings_morph.open()` and set `animating`.
- **Close paths:** `CloseSettings`, Esc, a click outside the panel (a full-window `mouse_area` layer, as for notes) and `WindowUnfocused` all close the panel. Opening a note closes settings.
- **Tick:** ticks `settings_morph`. When the morph is closed and `settings_open` is set, it sets `settings_open = false` and `palette_slot = None`.
- **Slider changes:** `SettingChanged(k, v)` calls `settings_mut().set(k, v)` followed by `apply_settings()`. `ResetGroup(g)` calls `reset(g)` followed by `apply_settings()`. For `Palette`, the reset also recolors every changed slot's notes from old to default.
- **Palette slots:** `PaletteSlotSelected(i)` toggles the selection (selecting the same slot again gives `None`).
- **Palette colors:** `PaletteColorChosen(c)` looks up the old color at the slot. It then calls `store.recolor(old, c)`, which marks the store dirty if it returns true. Finally it sets `palette[slot] = c`, marks settings dirty and keeps the slot selected.
- **Shortcut:** in `Key`, `Character(",")` with `modifiers.command()` sends `ToggleSettings`. Esc closes settings before notes.
- **Passthrough:** `is_interactive` also returns true over `settings_frame().rect.expand(8.0)`.

**Panel view:**
- **Card:** a dark card with background `Color::from_rgb(0.13, 0.13, 0.15)`, radius 10 and the same shadow as the note. Content alpha comes from the morph frame.
- **Header:** a row with "Settings" and a × button that sends `CloseSettings`.
- **Scrolling:** a `scrollable` column holds the five slider groups and Palette.
- **Group header:** the group name plus a small "Reset" text button.
- **Slider row:** `row![text(label), Space fill, text(key.format(v))]` above `slider(key.range(), v, move |v| SettingChanged(key, v))`. The step is 0.01 for tint, alpha, speed and fraction, 0.1 for magnification and peek delay, and 1 otherwise.
- **Palette section:**
  - The 20 swatches are shown 5 per row, 28 px each. The selected one gets a white 2 px ring.
  - Below the swatches, when a slot is selected, the 60 presets appear 12 per row, 20 px each.
  - Reuse the swatch styling helper from `color_picker.rs` by extracting `pub(crate) fn swatch(color, size, selected) -> container`.
